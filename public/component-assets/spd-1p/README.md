# SPD (Surge Protector) (`spd-1p`)

Surge protective device (SPD) modular: dasar DIN abu-abu terang dengan kartrid plug-in gelap, jendela indikator hijau, pelat label kosong; baut L dan N di atas, dua baut PE di bawah.

## Status gambar
`physical.png` adalah **ilustrasi buatan AI**, bukan foto produk pabrikan. Dibuat dari kode SVG lalu dirender ke PNG 1280x1280 px (RGBA, latar transparan). Bentuk generik: tanpa merek, logo, teks, atau angka rating.
